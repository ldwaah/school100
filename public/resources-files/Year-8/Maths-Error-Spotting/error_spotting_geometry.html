Become an Error Detective!

Finding mistakes in calculations is an important skill! This resource focuses on to spot errors in addition and subtraction problems. Look carefully at each calculation, find what's wrong, and explain the mistake!

Getting Started: How to Spot Errors

When checking calculations, look for these common mistakes:

Common Addition Errors

• Forgetting to carry numbers

• Adding incorrectly in columns

• Not lining up numbers properly

• Missing digits when copying

Common Subtraction Errors

• Forgetting to borrow

• Borrowing incorrectly

• Subtracting the wrong way round

• Not checking the answer makes sense

Example: Spot the Error

Calculation:

  347
+ 285
────
  522

What's wrong? The ones column: 7 + 5 = 12, but they wrote 2 and forgot to carry the 1 to the tens column!

Correct answer: 632

Top Tips for Error Spotting:
  • Work through the calculation yourself
  • Check each step carefully
  • Look for place value mistakes
  • Check if the answer makes sense (estimate first)
  • Look for missing carries or borrows
