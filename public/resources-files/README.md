# 100% Resources - How to Add Content

This folder contains all the academic resources for students. Resources are organised by subject and category.

## Folder Structure

```
resources-files/
├── english/
│   ├── reading/          (10 resources)
│   ├── writing/          (5 resources)
│   └── vocabulary-spag/  (5 resources)
├── maths/
│   ├── practice/         (10 resources)
│   └── error-spotting/   (5 resources)
├── sport/
│   ├── academic/         (10 resources)
│   └── assessment/       (5 resources)
└── trust/
    └── employability/    (10 resources)
```

## How to Add Resources

### Step 1: Create Your Resource

Create your resource as a **PDF** or **Word document** (will be converted to PDF for viewing).

**Resource should include:**
- Clear title
- Instructions
- Exercises/activities
- Self-contained content (no external links/videos)

### Step 2: Name Your File

Use descriptive names:
- Good: `Year_7_Reading_Comprehension_Exercise_1.pdf`
- Good: `Maths_Fractions_Practice_Sheet.pdf`
- Bad: `resource1.pdf`

### Step 3: Place in Correct Folder

Copy your file to the appropriate folder:

**English:**
- Reading → `english/reading/`
- Writing → `english/writing/`
- Vocabulary & SPaG → `english/vocabulary-spag/`

**Maths:**
- Practice → `maths/practice/`
- Error Spotting → `maths/error-spotting/`

**Sport:**
- Academic → `sport/academic/`
- Assessment & Analysis → `sport/assessment/`

**King's Trust:**
- Employability → `trust/employability/`

### Step 4: Test

1. Restart the server (if running)
2. Go to http://localhost:3000
3. Click "100% Resources"
4. Click the relevant category
5. Your resource should appear!

## File Types Supported

- ✅ PDF (recommended)
- ✅ Word (.docx)
- ✅ PowerPoint (.pptx)
- ✅ Text files (.txt)
- ✅ Images (.jpg, .png)

## Tips

1. **PDFs work best** - they display consistently on all devices
2. **Keep file sizes reasonable** - under 10MB per file
3. **Use clear naming** - students will see the filename
4. **Number your resources** - e.g., "Exercise_01", "Exercise_02"
5. **Include answers** - either at the end or as a separate file

## Updating Resources

1. Replace the file in the folder (same name)
2. Or delete the old file and add the new one
3. Restart the server
4. Resources update automatically
